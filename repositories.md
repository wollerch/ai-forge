A curated list of repositories that are useful for agentic engineering and daily experimentation.

## Frameworks and Orchestration

- [microsoft/autogen](https://github.com/microsoft/autogen) — Multi-agent framework for building collaborative AI systems.
- [crewAIInc/crewAI](https://github.com/crewAIInc/crewAI) — Role-based multi-agent workflows.
- [langchain-ai/langchain](https://github.com/langchain-ai/langchain) — Tooling for LLM application orchestration.

## Prompting and Evaluation

- [openai/evals](https://github.com/openai/evals) — Evaluation framework for measuring model behavior.
- [promptfoo/promptfoo](https://github.com/promptfoo/promptfoo) — Prompt testing, regression checks, and red-team style evaluation.

## Agent Runtime and Tooling

- [microsoft/semantic-kernel](https://github.com/microsoft/semantic-kernel) — SDK for agents, memory, and plugin-based tooling.
- [Significant-Gravitas/AutoGPT](https://github.com/Significant-Gravitas/AutoGPT) — Autonomous-agent experiments and patterns.
